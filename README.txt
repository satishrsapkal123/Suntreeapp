SUNTREE BUSINESS DESK - INSTALL GUIDE
1. Upload everything in this folder (index.html, sw.js, manifest.webmanifest, icons/) to any free HTTPS host:
   Netlify Drop (app.netlify.com/drop), GitHub Pages, Cloudflare Pages or Firebase Hosting.
2. Open the https link on the phone in Chrome -> tap "Install app" (button on Home) or menu -> Install app.
   iPhone: open in Safari -> Share -> Add to Home Screen.
3. Windows/Mac: open the link in Chrome/Edge -> install icon in the address bar.
Notes: installing needs HTTPS (it will not install from a file on disk). After the first open, the app works offline;
the PDF/OCR helper libraries load from the internet once and are then cached.
Data is saved in that browser/app only - use the PDF downloads as your backup.
For a real Android APK file, paste the hosted link into pwabuilder.com and download the Android package.
